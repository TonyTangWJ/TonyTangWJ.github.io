01 / Toolset

四个工具
一条验证链路

将取数、转换、核验和执行拆解为清晰而可衔接的能力模块，减少人工整理与重复操作，把时间留给问题分析与业务判断。

01

SQL 取数

从 ECC Oracle 或 S/4 HANA 执行标准化查询，按任务导出 CSV 数据集。无需人工登录 SAP 查数、复制和整理，即可快速准备迁移核验与质量分析所需的同口径数据。

价值交付快速取数与报告展示，让数据准备从人工动作变成可重复任务。
02

Python 数据对比

对比 PreLoad 与 PostLoad 的主键、记录数量和字段值差异。支持先对迁移前数据进行格式、字段取值和业务规则转换，再按等价规则核验，减少非实质性差异的干扰。

价值交付生成 HTML 数据验证报告，直观定位缺失、重复、错配和字段不一致。
03

VBA 数据对比

以 Excel 工作簿呈现迁移前后数据的核验结果，支持数据转换和主键配置。每项任务在模板临时副本中写入数据、执行固定宏并输出结果，保护标准模板且支持单进程或多进程运行。

价值交付生成可筛选的 Excel 差异明细报告，便于人工复核、沟通与验收留档。
04

SAP GUI 自动化

基于 Python、pywin32 与 SAP GUI Scripting，支持自动登录、轮询记录多个 Session 的原生 VBS 操作，并为后续回放和控件树提取保留扩展边界。

价值交付自动化批量执行 SAP 操作，沉淀可复用的业务流程与回归测试基础。
