# SQL 取数用户说明

## 1. 用途

SQL 取数工具用于从源系统和目标系统提取待验证的数据，为数据迁移核验、系统升级检查和数据质量分析准备统一的对比资料。它可将各业务对象的数据导出为标准化文件，降低人工查数、复制和整理数据的工作量。

该工具特别适合在 ECC 与 S/4 等系统之间准备同口径的数据集。通过按任务组织取数结果，团队可以更高效地完成多表、多对象和多轮次的数据准备，并将输出直接用于后续的数据校验、问题分析和项目交付留档。

SQL 程序从 ECC Oracle 或 S/4 HANA 执行查询，并将每一条任务的结果导出为 CSV。任务数据存放在 CSV 中，运行参数和数据库连接信息分别存放在 JSON 中。
