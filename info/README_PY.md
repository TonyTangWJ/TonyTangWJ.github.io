# Python 数据校验用户说明

## 1. 用途

Python 数据校验工具用于核对迁移、转换或加载前后的结构化数据是否一致。它以迁移前数据（PreLoad）和迁移后数据（PostLoad）为对比对象，识别两侧在主键、记录数量和字段值上的差异，帮助项目团队快速发现缺失记录、重复记录、主键错配及业务字段不一致等问题。

该工具支持先对迁移前数据进行转换，再与迁移后数据进行对比。对于不同系统间因字段取值、数据格式或业务规则差异导致的数据不一致，可先将迁移前数据转换为与目标系统一致的业务口径，再开展核验，从而减少非实质性差异对结果的干扰。

该工具适用于主数据、配置数据和业务数据的批量核验。校验结果可按任务输出差异明细和汇总信息，为数据修复、问题定位、迁移验收和质量追踪提供清晰依据。
