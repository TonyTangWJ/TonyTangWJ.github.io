# VBA 数据校验用户说明

## 1. 用途

VBA 数据校验工具用于以 Excel 工作簿形式呈现迁移前后数据的核验结果。它将迁移前数据（PreLoad）与迁移后数据（PostLoad）进行对比，并生成便于浏览、筛选和沟通的差异报告，帮助业务人员和项目团队直观确认数据一致性。

该工具适合需要使用 Excel 进行人工复核、问题讨论和验收留档的场景。报告可用于识别主键、记录和字段值差异，使非技术使用者也能快速查看异常数据、跟踪修复进展，并作为数据迁移质量确认的交付材料。

VBA 校验程序将 PreLoad 与 PostLoad CSV 写入 Excel 模板，填写主键配置后调用固定 VBA 宏生成差异结果工作簿。

运行时不会直接写入标准模板：每个任务都会先创建模板的临时副本，在副本中写数据和运行宏，最后将结果另存到输出目录。单进程和多进程均使用该机制。
