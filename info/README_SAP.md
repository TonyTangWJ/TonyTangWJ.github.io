
# SAP AutoTest

基于 Python 3.14、pywin32 和 SAP GUI Scripting 的 SAP 自动化工具。当前包含 SAP 登录、轮询式多 Session 原生 VBS 录制，以及后续回放和控件树提取的扩展边界。

## 用途说明

SAP AutoTest 面向需要重复操作 SAP 的业务、测试和开发人员，用于记录业务操作、整理操作步骤，并逐步形成可复用的自动化任务。它适用于交易码操作记录、回归测试准备、业务流程梳理和自动化脚本开发。

## 能提供的帮助

- 自动完成 SAP 登录，减少重复输入连接与账号信息的工作。
- 记录用户在 SAP 中的操作过程，便于复盘、分享和整理标准操作流程。
- 支持同时记录多个窗口中的操作，避免遗漏并行处理的业务步骤。
- 汇总操作中填写和选择的信息，为测试用例设计、数据准备和参数化提供参考。
- 帮助定位页面字段和控件，降低编写自动化脚本时查找元素的成本。
- 为重复性业务操作、回归验证和日常测试提供可复用的自动化基础。
